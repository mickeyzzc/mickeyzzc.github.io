Domestic LLM Resource and Cost Comparison: GLM-5.3 / Kimi K3 / MiniMax M3

March 23, 2026 September 23, 2026 AI Tools GLM, Kimi, MiniMax, LLMs 899 words 5 min read
🔊

Overview

This post was first published in 2026-03 comparing GLM-5 / Kimi K2.5 / MiniMax M2.7; it was updated in 2026-09 to the three vendors’ current flagships. Data is as of 2026-09-23, using public list prices — every vendor repriced multiple times this year, so check the official pricing pages before you buy.

The theme of the past six months has been generation jumps plus price hikes: Kimi’s flagship input price went up 5×, GLM raised prices 67%-100% versus the GLM-4 era, and the industry-average Chinese API price reached ¥4.9 input / ¥21.9 output per million tokens in 2026Q2.

GLM-5.3 (Zhipu AI)

Versions and Hardware Requirements

The lineage runs GLM-5 (open-sourced 2026-02 under MIT, 744B total / 40B active, 200K context) → GLM-5.1 → GLM-5.2 (context extended to 1M, open weights) → GLM-5.3. Version 5.3 shares the 5.2 base model; all gains come from post-training, targeting complex coding and agent tasks.

  • GLM-5.3: flagship, 1M context, 128K max output.
  • GLM-5.3-Flash: lightweight tier, 1M context, the first open frontier model using a sparse + linear attention hybrid; thinking mode always on; fully rolled into the GLM Coding Plan.

Local deployment: FP8 full precision needs roughly 860GB of VRAM, typically 8× B200 (192GB); 1M context adds about 103GB of KV Cache. Community 8-24GB low-bit quantization recipes exist — fine for experiments, not for production.

On subscriptions, the GLM Coding Plan entry tier is around ¥132/quarter after several price hikes this year.

Kimi K3 (Moonshot AI)

Versions and Hardware Requirements

Kimi K3 was released on 2026-07-17: 2.8T total parameters, one of the largest open models in the world; 1M context; in-house KDA (Kimi Delta Attention) hybrid linear attention with attention residuals; natively multimodal. Weights are open, but only a server cluster can host this thing.

The mid-tier on sale is K2.6 and K2.7 Code ($0.95 input / $4.00 output per million). K2.5 ($0.60/$3.00), which the original edition compared, is still sold but no longer the main act.

MiniMax M3

Versions and Hardware Requirements

MiniMax M3 was released and open-sourced on 2026-06-01: 428B total / 23B active, MSA sparse attention (official figures: 9.7× faster prefill, 15.6× faster decode), natively multimodal, 1M context (1,048,576 tokens), thinking and non-thinking modes.

The previous generation M2.7 (released 2026-03-18, open-sourced in April, 229B MoE) is still on sale as M2.7 and M2.7-highspeed — same results, the latter faster.

Local deployment: 428B/23B is the lowest bar among the three flagships; quantized, it runs on a multi-GPU workstation (8× A100/H100 class) — the realistic self-hosting option.

Recommendations

Cheap and high-volume: GLM-5.3-Flash or MiniMax M3; subscription plans (GLM Coding Plan / MiniMax Token Plan) usually beat pay-as-you-go.

Coding and agent workhorse: GLM-5.3 — at ¥8/¥28 list, the best value among the three flagships.

Capability ceiling first: Kimi K3 — 2.8T parameters, 1M context, natively multimodal, and the most expensive in China.

Local deployment: all three flagships are server-class — GLM wants 8× B200 or more, K3 is cluster-level, and M3’s 428B/23B is the most realistic on a multi-GPU workstation. Consumer GPUs are left with community low-bit quantization: fine for tinkering, not for production.

Summary

The story of the first half of 2026 was generation jumps plus price hikes: flagships keep getting more expensive (Kimi K3 output at ¥100/M), and the cheap tier moved from “affordable flagships” to Flash/lightweight models and subscription plans. Pick by need today: Flash tier and Token Plans for high-volume cheap calls, GLM-5.3 as the coding workhorse, K3 for the capability ceiling. Data as of 2026-09-23; vendors reprice often, so verify the official pricing pages before you buy.
