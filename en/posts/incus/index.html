Storage Choices and Memory Budget on a 16 GiB Box

November 4, 2026

The storage backend decides more than performance — it decides whether migration is a downtime event or a live one. That is the one sentence this post rests on. Along the way: the memory budget for a 16G box, because an uncapped ZFS ARC is a memory thief. The conclusion first incus move fundamentally means moving instance disks from A to B: If A and B share one storage (Ceph and friends), no data moves — only runtime state does → live migration, no downtime; With local disks on each node (my case), data is physically copied → downtime migration, seconds to tens of seconds for containers, longer for VMs. So the first storage question is not “which is fastest” but “am I willing to pay Ceph’s price for zero-downtime migration”. My answer: no. Two 16G boxes cannot carry Ceph’s minimum of 3 monitors + OSDs, and “no mutual replication” makes its replication useless here. Accept the short downtime window on local disks — that is the entire cost.
