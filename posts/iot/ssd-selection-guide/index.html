SSD 选购分析 —— 形态、协议与颗粒，从 SATA 到 PCIe 5.0 NVMe

July 27, 2026 物联网 SSD, NVMe, PCIe, 硬件选型, 闪存 技术与工程选型系列 2912 字 6 分钟阅读
🔊

顺序峰值与实际负载的差距

SSD 的标称速度是顺序读写峰值，但系统盘、软件启动这类常见负载的瓶颈主要在 4K 随机读写。从 SATA 升级到 PCIe 3.0 NVMe 是性能质变，但从 PCIe 4.0 升级到 5.0，对系统启动、日常软件响应这类负载的感知差异通常很小，主要收益体现在大文件顺序传输（如虚拟机镜像、视频素材拷贝）。

选购前应先判断自身负载的瓶颈位置，再决定是否需要为 PCIe 5.0、独立 DRAM 缓存这类规格支付溢价。

下面按这四件事展开。

形态：插槽与尺寸的约束

形态尺寸接口典型场景
2.5" SATA100×70×7mmSATA 数据+电源老电脑、NAS 盘位
M.2 228022×80mmM key（NVMe）或 B+M key（SATA/NVMe）笔记本、台式机系统盘
M.2 223022×30mmM keySteam Deck、掌机、迷你主机
M.2 2211022×110mmM key企业级、工作站
U.2 / U.32.5" 但针脚不同SAS/SATA/NVMe服务器热插拔
EDSFF (E1/E3)长条形PCIe数据中心

消费级最常见的是 M.2 2280。选购前确认两点：

  1. 主板是否有 M.2 插槽，以及支持 SATA 还是 NVMe（老 Z97 主板的 M.2 仅走 SATA）。
  2. M.2 针脚是 M key 还是 B+M key。B+M key 缺两个口，兼容性好但只能走 PCIe ×2；M key 缺一个口，走 PCIe ×4，是 NVMe 满速的形态。

2230 尺寸由于 Steam Deck 和掌机的普及而流行，但容量上限较低（多为 512GB–2TB）。

协议与总线：速度上限

协议 / 总线理论带宽实测顺序读代表盘
SATA III6 Gbps~550 MB/s三星 870 EVO、Crucial MX
NVMe / PCIe 3.0 ×4~4 GB/s~3500 MB/s三星 970 EVO Plus、WD SN770
NVMe / PCIe 4.0 ×4~8 GB/s~7000 MB/s三星 990 PRO、WD SN850X、致钛 TiPlus 7100
NVMe / PCIe 5.0 ×4~16 GB/s~14000 MB/s致钛 TiPro7000、Crucial T700

注意 NVMe 和 SATA 的差距（550 → 3500）远大于 PCIe 3.0 到 5.0 的差距（3500 → 14000）的边际收益。从 SATA 升级到 PCIe 3.0 NVMe 是质变；从 PCIe 4.0 升到 5.0 多数负载感知差异很小——除非涉及大量顺序大文件读写或视频剪辑。

PCIe 5.0 盘发热严重，几乎都强制配备散热片，部分主板甚至要求主动风扇。迷你机箱和笔记本基本无法使用 PCIe 5.0。

DRAM 缓存：影响持续性能

SSD 的 FTL 映射表（逻辑地址 → 物理块）需要存放在某处，三种方案：

方案原理优点缺点典型盘
独立 DRAM自带 DDR 缓存芯片性能稳定、寿命长贵、占空间三星 990 PRO、WD SN850X
DRAM-less + HMB借主机内存 64MB 存映射表便宜、空间小满载时可能掉速WD SN770、致钛 TiPlus 7100
独立 SLC 缓存切一部分 NAND 当 SLC突发写入快缓存用完后掉速严重多数中低端盘

关键约束：HMB（Host Memory Buffer）依赖主机内存，PS5 和部分老主板不支持 HMB，这类盘装上去会严重降速。选购 DRAM-less 盘用于 PS5 时，必须查官方兼容列表。

高端盘采用混合策略——三星 990 PRO 同时具备独立 DRAM 和 SLC 缓存，兼顾稳定性和性能，价格也最高。

NAND 颗粒与掉速

颗粒类型（SLC/MLC/TLC/QLC）的 P/E 寿命差异在 SD/TF 卡和 U 盘那两篇讲过，SSD 同理：

颗粒P/E 循环当前主流用途
SLC~100,000工业级、企业级缓存
MLC3,000–10,000已退出消费市场
TLC1,000–3,000消费主流
QLC100–1,000大容量低价盘

SLC 缓存掉速机制是 QLC 盘的主要短板。主控把一部分 TLC/QLC 颗粒切成伪 SLC 模式当缓存，写入先进缓存（速度高），后台再搬运到 TLC/QLC 区。缓存写满后直写 QLC，速度从 2000MB/s 掉到 80–160MB/s。

QLC 盘（三星 870 QVO、Crucial P3 Plus）容量大、单价低，适合做仓库盘和冷数据。但不建议用作系统盘或工作盘——频繁随机写会快速消耗 SLC 缓存，触发持续掉速。

耐久：TBW 和 DWPD

指标含义典型值
TBW（Terabytes Written）生命周期内总写入量1TB TLC 盘约 600 TBW
DWPD（Drive Writes Per Day）每天可写满盘的次数（保修期内）消费级 0.3–1，企业级 1–10

1TB 的三星 990 PRO 标 600 TBW，按每天写 100GB 估算可用 16 年。消费级 SSD 多数不是被写坏的，而是随设备换代被换下——因此除 NAS/服务器 7×24 写入场景外，无需为高 TBW 支付溢价。

主控厂商

厂商中文定位特点
Samsung三星自产自销颗粒+主控+固件全自研
Phison群联高中端海盗船、Sabrent 高端盘
Silicon Motion (SMI)慧荣中端WD、Crucial 中端盘
Marvell迈威企业级Intel、Kioxia 企业级
Maxio联芸中低端国产 SSD 主力（致钛 TiPlus）
InnoGrit英韧中端国产，PCIe 4.0/5.0

联芸 MAP1602（PCIe 4.0 DRAM-less）撑起了国产 SSD 的性价比——致钛 TiPlus 7100 用它做到 7000MB/s 读、价格只有三星 990 PRO 的一半。

场景选型

系统盘

认 DRAM + TLC + PCIe 4.0。系统盘负载是大量小文件随机读写，DRAM 缓存保证 FTL 映射稳定，PCIe 4.0 是当前甜点。

产品容量协议颗粒/缓存参考价
三星 990 PRO1TBPCIe 4.0TLC + DRAM~¥700
WD Black SN850X1TBPCIe 4.0TLC + DRAM~¥650
致钛 TiPlus 71001TBPCIe 4.0TLC + HMB~¥450
Samsung 870 EVO1TBSATATLC + DRAM~¥550

老电脑只有 SATA 接口就选 870 EVO，别强上 NVMe。

游戏盘

认 PCIe 4.0 + DirectStorage 支持。DirectStorage 让 GPU 直接读 SSD，绕过 CPU，加载速度提升明显（PS5、Xbox Series 同款技术）。容量至少 2TB。

产品容量协议特点参考价
WD Black SN850X2TBPCIe 4.0游戏优化固件~¥1200
三星 990 PRO2TBPCIe 4.0顶级性能~¥1300
Crucial T5002TBPCIe 4.0性价比之选~¥900

笔记本

认 M.2 2280 + 低功耗 + 单面颗粒。笔记本空间小，双面颗粒的盘装不进去；功耗高的盘会缩短续航。

产品容量功耗特点参考价
WD Blue SN5801TB低DRAM-less 省电~¥400
致钛 TiPlus 71001TB低HMB 不依赖独立供电~¥450
Samsung 990 PRO1TB中性能强但耗电~¥700

NAS 和服务器

认企业级 + PLP（掉电保护）+ 高 DWPD。NAS 7×24 写入，必须选企业级盘，消费级盘半年就坏。PLP 用电容在断电时把缓存数据刷入颗粒。

产品容量协议特点参考价
Samsung 983 ZET1.92TBSATA企业级 TLC + PLP~¥2500
WD Red SN7002TBSATANAS 专用~¥1500
Micron 7450 Pro3.84TBPCIe 4.0企业级 NVMe + PLP~¥6000
Kioxia CD63.84TBPCIe 4.0U.2 企业级~¥5500

NAS 用 SSD 主要做缓存加速（读缓存或 SSD 层），主存储还是机械盘——见下一篇。

PS5 扩展

索尼要求 PCIe 4.0 NVMe + 散热片。容量 250GB–8TB，DRAM-less 盘可能不兼容（PS5 不支持 HMB）。

产品容量是否带散热片参考价
WD Black SN850X1TB有/无版可选~¥700
Samsung 990 PRO1TB有版可选~¥750
致钛 TiPro 70001TB带散热片~¥600

PS5 必须装散热片，裸条会因高温降速甚至触发保护。

选盘速查

场景认什么推荐产品
系统盘（台式机）PCIe 4.0 + DRAM + TLC三星 990 PRO、WD SN850X、致钛 TiPlus 7100
系统盘（老电脑）SATA III + DRAMSamsung 870 EVO、Crucial MX500
游戏盘PCIe 4.0 + 2TB+WD SN850X、三星 990 PRO、Crucial T500
笔记本M.2 2280 单面 + 低功耗WD SN580、致钛 TiPlus 7100
NAS / 服务器企业级 + PLP + 高 DWPDSamsung 983 ZET、WD Red SN700、Micron 7450
PS5 扩展PCIe 4.0 + 散热片 + DRAMWD SN850X、三星 990 PRO、致钛 TiPro 7000
仓库盘 / 冷数据QLC 大容量Samsung 870 QVO、Crucial P3 Plus

通用一条：买前查主板支持的协议和插槽形态，别买回来插不上。PCIe 5.0 是当前性能天花板，但发热和价格都高，非必要不追。
