PTZR 横滚轴：第四自由度与地平线锁定

August 3, 2026 物理世界开发 PTZ, PTZR, 横滚轴, 地平线, 稳定云台 信号与图像处理系列 12906 字 26 分钟阅读
🔊

PTZ 的三根轴解决"看哪里、看多大": Pan(Yaw,绕垂直轴)定方位,Tilt(Pitch,绕水平横轴)定俯仰,Zoom 定焦距。Roll(绕光轴自身的旋转)不决定看哪里,只决定画面"转没转"——也就是地平线平不平。

当摄像机装在不水平、会晃、会转的平台(车/船/无人机/摇臂/机械臂)上时,两轴云台结构性地无法保持地平线: Pan 轴刚性绑定载体 Z 轴,载体一倾斜,Pan 轴就不是真铅垂线,画面 Roll 无处可去。这不是安装误差,是缺一个自由度。PTZR 补上 Roll 轴,把"地平线水平"从不可能变成可解,代价是机械、控制、标定复杂度上一个台阶。

前一篇强调的长焦放大效应,对 Roll 要分两面看: 纯 Roll 角度误差的像素代价 Δpx = r·θ 与焦距无关; 真正被焦距放大的是 Roll 轴偏心视差 Δpx = f_px · d·sinφ / L,那是长焦近景的杀手,后面详述。

PTZR 定义与四自由度

PTZR 在 Pan / Tilt / Zoom 三自由度之外增加第四根 Roll 轴。四根轴的分工:

轴旋转轴作用典型行程
Pan (Yaw)垂直轴方位指向360° 连续
Tilt (Pitch)水平横轴俯仰指向−30° ~ +90°
Zoom—焦距 / FOV20x ~ 30x
Roll光轴自身地平线水平 / 画幅旋转±15°(广播型) ~ ±90°(创作者型)

产品分两派:

  • 广播 / 安防型: 只做小行程水平校正(±15°),Bolin SD530H 把 Roll 做成 “Image Rolling Adjustment” 菜单项,多为手动 / 半自动调平,非实时增稳。
  • 创作者 / 影视型: 做大幅物理转轴。OBSBOT Tail 2 物理 ±90° 转竖屏拍短视频,标称角抖 ±0.003°;MRMC Bolt 这类 Cinebot 机械臂 Roll 行程 ±270° @ 870°/s,Roll 是主动创作轴而非补偿轴。

对照:Sony FR7 / BRC 系列无独立横滚机械轴,地平线只能靠电子 / 光学补偿。公开规格未列 roll 项,不是"有但没用上",是根本没有。

上图画的是四根轴的几何分工: 前三根决定相机"指向哪、取多大景",Roll 是唯一不改变指向的轴——它绕光轴转,只改变画面姿态。这也是为什么常规 PTZ 场景(固定杆、桌面)里 Roll 显得多余,换到倾斜平台上就变成必需。

为什么 PTZ 在倾斜平台上会歪

两轴云台的 Pan 轴刚性绑定载体 Z 轴。载体(车/船/臂)自身不水平时,Pan 轴就不是真铅垂线,绕它转动的只能是"斜交于水平面"的方位角——画面整体带一个随 Pan 变化的 Roll 分量,且无处补偿。

这不是安装误差,是自由度缺失: Roll 是绕光轴自身的旋转,数学上无法由 Pan / Tilt 两个旋转合成。两轴机构只覆盖两个旋转自由度,基座引入的第三个姿态自由度(横滚)没有对应的轴去抵消。装得再正也没用,因为平台在动。

运动学与耦合

设相机光轴单位向量在载体坐标系下为:

1

x_c = ( cos t·cos p ,  cos t·sin p ,  −sin t )        // p = pan, t = tilt

载体相对水平面的小失准向量 δ = (φ_b, θ_b, δ_ψ)(前向滚转 / 侧向俯仰 / 航向)。图像 Roll 即 δ 在光轴上的投影(一阶近似):

1

ρ ≈ δ · x_c = cos t · (φ_b·cos p + θ_b·sin p) − δ_ψ·sin t

这条公式是理解 PTZR 一切工程决策的核心,三个直接结论:

  1. Pan 会"连累"Roll。载体固定倾斜下,只做一次 Roll 归零,Pan 扫过 360° 时 ρ 按正弦重现,幅值 = √(φ_b²+θ_b²) = 载体倾角。船体横摇 5°、Pan 转 90°,图像 Roll 就从 0 摆到 5°。→ Roll 必须随 Pan/Tilt 实时联动,静态标定一次解决不了。
  2. Tilt 抑制横滚。cos t 因子说明大仰角时载体倾斜对 Roll 的贡献变小,但 δ_ψ·sin t 项接管——抬头时航向误差直接变成画面旋转。
  3. 天顶奇点。t → ±90° 时光轴与铅垂轴平行,Pan 与 Roll 产生完全相同的图像效果,雅可比降秩(万向锁)。过顶保持地平线需要 Pan 瞬时 180° 翻转(速率 → ∞)。工程做法: 设 70° 告警 / 85° 冻结,或加第四根冗余轴主动维持轴间夹角;姿态解算全程用四元数,只在末端解算电机角。

Roll 的像素代价: 与焦距无关

距画面中心 r 像素处,Roll 误差 θ 造成切向位移:

1

Δpx = 2r·sin(θ/2) ≈ r·θ[rad]
分辨率角点 rθ=0.1°θ=0.3°θ=1.0°
1080p1101 px1.9 px5.8 px19 px
4K UHD2203 px3.8 px11.5 px38 px

修正常见误解:纯 Roll 像素代价与焦距无关。30x 下 0.3° 难忍的真实原因有三个: ① 4K 角点 11.5 px 往复抖动在 1/50s 快门下即可见拖影; ② 长焦时 pan/tilt 残差已经吃掉全部误差预算,Roll 没有余量; ③ 真正被焦距放大的是下一节的 Roll 轴偏心视差。

横滚轴机械: 轴必须压在光轴上

旋转型视差(Roll-axis parallax): 若 Roll 旋转中心偏离光轴 d,转动 φ 时入瞳横移 Δ = d·sinφ,对距离 L 的被摄物形成视差角 α = d·sinφ / L,像素位移:

1

Δpx = f_px · d·sinφ / L ,其中 f_px = 图像宽 / (2·tan(HFOV/2))

取 d = 0.5 mm、φ = 15°(Δ = 0.13 mm)、1920 宽:

变焦HFOVIFOVL=5 mL=1 m
广角63°573 µrad/px0.05 px0.23 px
30x 长焦2.3°21 µrad/px1.2 px6.2 px

即 d < 0.5 mm 在广角完全无感,长焦近景就是数像素级整体平移 + 近远景不同步的梯形 / 透视畸变。若要求 30x、L=2 m 下 <1 px,需 d·sinφ < 42 µm → d < 0.16 mm。这是装配硬约束: Roll 轴承同心度、镜头组光轴与机械轴对准,通常靠出厂光学打靶 + 偏心垫片补偿。

布置选择两条路:

  • 转整个光机块(镜头 + sensor): 光轴与机械轴天然共轴,无镜-感失配,代价是转动惯量大(Tail 2 整机 1.066 kg)。
  • 只转 sensor: 惯量最小、带宽最高,但 sensor 中心与光轴偏心 d 直接暴露,且需柔性排线(寿命 / 回弹力矩)。

Roll 电机扭矩最小(典型 0.020.1 N·m 直驱 BLDC); 用减速箱会引入 0.020.1° 背隙,直驱无背隙但需大电流保持力矩。带宽阶梯典型: Pitch 30~60 Hz > Roll 15~30 Hz > Yaw 10~20 Hz(Yaw 惯量最大)。Roll 常是稳定链路的实际短板。

自动水平控制(Horizon Lock)

方案 A: IMU / 陀螺。加速度计给长期水平基准(互补滤波截止 0.050.5 Hz),陀螺给短期高带宽(>0.5 Hz),环路 2001000 Hz。不依赖场景、延迟 <5 ms。缺点: 消费级 MEMS 零偏不稳定 10100 °/h,加计零偏温漂使 Roll 零位漂 0.050.3°/10 ℃; 载体横向加速度污染重力基准(车辆转弯"假倾斜"),需车速 / GNSS 或转弯率补偿。

方案 B: 视觉地平线。中值滤波 → Canny 边缘 → Hough 变换取直线 → 约束筛选(长度 / 贯穿性 / 天顶消失点几何)→ RANSAC / 最小二乘拟合 → 反解 Roll。精度 0.10.5°,延迟 24 帧(60130 ms),只能做慢外环(<12 Hz)。纯天空 / 雾天 / 密林 / 长焦特写等无地平线场景直接失效,需置信度门限 + 优雅退化。

方案 C(主流): 融合。IMU 跑内环粗稳(高带宽),视觉以 0.1~1 Hz 在线估计并抵消 IMU 零偏(EKF 中把 Roll bias 作为状态量)。等效"陀螺管动态、视觉管静态",既消漂移又不受帧率限制。

三轴稳定是三路串级环: 电流环 1020 kHz → 角速率环(陀螺反馈)5001000 Hz → 角度 / 姿态环 100~200 Hz。两个关键点:前馈把载体 IMU 角速率直接送到各轴速度指令,不等误差累积——这是三轴云台优于两轴的核心;解耦把 cos t·(φ_b·cos p + θ_b·sin p) 前馈给 Roll 轴,避免 Roll 环去"追"自己造成的可预测误差。相对 PTZ,控制器算力与内存约 +50%。

4-DOF 标定在 PTZ 三维查找表之上追加: Roll 机械零位(水平仪 / 自准直仪基准,<0.05°)、Roll–光轴同心度(远近双靶标法反解 d,垫片补偿至 <0.2 mm)、Roll 与 Pan/Tilt 正交度。长期漂移: 结构蠕变 + 温漂使 Roll 零位年漂 0.10.3°,建议整机 312 个月复标,或在线自标定——静止且有可靠地平线时用视觉估计值刷新零位。

机械 Roll vs 电子 Roll(EIS 裁切)

数字旋转需预留裁切余量,等比裁切系数近似 s ≈ 1/(cosθ + (h/w)·sinθ):

支持 roll 范围线性裁切面积损失4K 有效分辨率广角 63° HFOV 剩余
±5°4.3%8.4%3675×206760.8°
±10°7.6%14.6%3548×199659.0°
±15°10.0%19.0%3456×194457.4°

行业通用 EIS 裁切量 5~20%。电子法的三条硬边界:

  1. FOV 不可逆损失,广角端损失最刺眼(上表 4~6°);
  2. 长焦端不可用: 裁切百分比与焦距无关,但长焦本已进入数字变焦区、无冗余像素,再裁 10% 直接掉 MTF,旋转重采样再降 10~20% 锐度;
  3. 旋转中心必须 = 光心。若已做数字 pan/tilt 裁切,旋转中心偏离光心 Δc,旋转 φ 会额外引入平移 Δc·2sin(φ/2) 与残余梯形——正是"数字防抖画面边缘游走"的成因。

选型边界: 长焦(>10x)、需保全 FOV、船载 / 车载 / 摇臂等大幅持续倾斜 → 必须机械 Roll; 广角、θ < 5°、成本 / 体积敏感、纯手持微抖 → EIS Roll 足够; 高端方案是机械粗稳(±15°,15~30 Hz) + EIS 精修(±1°,逐行 rolling shutter 校正),机械管幅值、电子管高频与果冻效应,裁切压到 3% 以内。

PTZR 特有的稳定性问题

  • 共振模态 2→3: 内层 Roll 框把 Pitch 框变成"带柔性支撑的悬臂",模态耦合。Notch 从 2 组变 3 组且互相牵连,需在线模态辨识而非固定 Notch。
  • Roll 轴带宽最窄(15~30 Hz),成短板: DJI Z15-A7 的 Roll 轴最大控速仅 ±30°/s,Pan/Tilt 是 ±130°/s(约 1/4)。Roll 电机在最内层、力矩臂最短、要驱动全部外层惯量,载体高频横摇(>20 Hz,车载路面激励典型)漏稳。缓解以机械为主(Gremsy T7 三轴统一到 180°/s)。
  • 延迟叠加与过冲: 控制回路 2→3 后,姿态解算(四元数 → 三轴解耦)+ 死区时间叠加,典型 +13 ms,三轴联动指令易在 Roll 上过冲。工程做法: 三轴共用同一 IMU 时间戳、统一 12 kHz 电流环、Roll 单独加低增益前馈。
  • 无地平线场景自动水平失效: 纯海面 / 雪原 / 天空 / 夜景无水平线特征 → 视觉法退化,必须 IMU 兜底;SOMAG 额外融合船 NMEA 数据抑制长期漂移。
  • 横滚偏心视差(未解决): Roll 轴需与光学入瞳 / 节点重合,装配偏心 δ 在物距 D、焦距 f 下像移 ≈ f·δ/D。长焦近景(f=550 mm、D=2 m、δ=0.2 mm)像移达 55 µm ≈ 十余像素,转 Roll 即"抖"。约束通常订到 <0.2 mm,量产良率是痛点。
  • 天顶奇点(tilt→±90°): Pan 与 Roll 轴共线,自由度塌陷。规避: ① 机械限位避开(H20T 可控 pitch 仅 −120°~+30°,刻意不给 ±90° 停留); ② 接近奇点时冻结 Roll 只用 Pan; ③ 四元数插值 + 奇点邻域速度限幅。

标准与生态: FreeD 天生带 Roll

FreeD(BBC R&D 起源)的 D1 包 29 字节,天然 6DOF + 2 镜头轴 = Pan / Tilt / Roll(各 24-bit,±180°,分辨率 1/32768°)+ X/Y/Z + Zoom/Focus + 校验位,UDP 默认端口 40000。虚拟生产(UE Live Link FreeD、disguise、Mo-Sys、stYpe、Ncam)开箱支持 Roll,PTZR 在 VP 中零协议改造成本。

缺口也在这里:ONVIF 无 Roll 字段(PTZ Vector 仅 PanTilt+Zoom)、VISCA 无 Roll 命令。厂商只能走私有扩展——Bolin 把 Roll 叫 “Image Rolling Adjustment ±15°” 挂在菜单外;OBSBOT 靠 WebUI / 私有 SDK。NDI 传视频不传位姿,Roll 元数据须旁路 FreeD。

PTZR 在 VP 的价值: AR 图层需要正确的 Roll 才不"漂"。Tail 2 用 ±0.003° 角抖 + FreeD + UE 插件,把 VP 入门成本从 stYpe / Mo-Sys 的十万美元级压到千美元级。

选型 Checklist

  • 平台静态倾角 >2° 或动态横摇 >1.5°(长焦 >20x → >0.3°)? 是 → 必须机械 Roll。
  • 需要保全 FOV(长焦 >10x)? 是 → 机械 Roll,放弃 EIS 旋转裁切。
  • 需要无损竖屏(短视频)? 是 → 物理 ±90° 转轴(OBSBOT Tail 2 类)。
  • 需要 VP / AR 图层? 是 → 必须支持 FreeD(含 Roll)。
  • Roll 轴偏心 d 装配公差 <0.2 mm(长焦近景 <0.16 mm)? 是 → 出厂打靶 + 垫片。
  • 会出现无地平线场景(海面 / 天空)? 是 → 必须 IMU 兜底 + 外部姿态源融合。
  • 需过顶拍摄(tilt→±90°)? 是 → 机械限位避开奇点,或四元数解算 + 速度限幅。

标准层面的终局与前文呼应: 多厂商标准分裂在 PTZ 时代是结构性问题,PTZR 更尖锐——ONVIF / VISCA 根本没有 Roll 字段,FreeD 虽带 Roll 但只用于 VP 小圈子。跨安防 / 广电 / 无人机三界的统一 Roll 元数据标准,目前还不存在。

PTZ 的三根轴解决"看哪里、看多大"：Pan（Yaw，绕垂直轴）定方位，Tilt（Pitch，绕水平横轴）定俯仰，Zoom 定焦距。Roll（绕光轴自身的旋转）不决定看哪里，只决定画面"转没转"——也就是地平线平不平。

当摄像机装在不水平、会晃、会转的平台（车 / 船 / 无人机 / 摇臂 / 机械臂）上时，两轴云台结构性地无法保持地平线：Pan 轴刚性绑定载体 Z 轴，载体一倾斜，Pan 轴就不是真铅垂线，画面 Roll 无处可去。这不是安装误差，是缺一个自由度。PTZR 补上 Roll 轴，把"地平线水平"从不可能变成可解，代价是机械、控制、标定复杂度上一个台阶。

前一篇强调的长焦放大效应，对 Roll 要分两面看：纯 Roll 角度误差的像素代价 Δpx = r·θ 与焦距无关；真正被焦距放大的是 Roll 轴偏心视差 Δpx = f_px · d·sinφ / L，那是长焦近景的杀手，后面详述。

PTZR 定义与四自由度

PTZR 在 Pan / Tilt / Zoom 三自由度之外增加第四根 Roll 轴。四根轴的分工：

轴旋转轴作用典型行程
Pan (Yaw)垂直轴方位指向360° 连续
Tilt (Pitch)水平横轴俯仰指向−30° ~ +90°
Zoom—焦距 / FOV20x ~ 30x
Roll光轴自身地平线水平 / 画幅旋转±15°（广播型）~ ±90°（创作者型）

产品分两派：

  • 广播 / 安防型：只做小行程水平校正（±15°），Bolin SD530H 把 Roll 做成 “Image Rolling Adjustment” 菜单项，多为手动 / 半自动调平，非实时增稳。
  • 创作者 / 影视型：做大幅物理转轴。OBSBOT Tail 2 物理 ±90° 转竖屏拍短视频，标称角抖 ±0.003°；MRMC Bolt 这类 Cinebot 机械臂 Roll 行程 ±270° @ 870°/s，Roll 是主动创作轴而非补偿轴。

对照：Sony FR7 / BRC 系列无独立横滚机械轴，地平线只能靠电子 / 光学补偿。公开规格未列 roll 项，不是"有但没用上"，是根本没有。

为什么 PTZ 在倾斜平台上会歪

两轴云台的 Pan 轴刚性绑定载体 Z 轴。载体（车 / 船 / 臂）自身不水平时，Pan 轴就不是真铅垂线，绕它转动的只能是"斜交于水平面"的方位角——画面整体带一个随 Pan 变化的 Roll 分量，且无处补偿。

这不是安装误差，是自由度缺失：Roll 是绕光轴自身的旋转，数学上无法由 Pan / Tilt 两个旋转合成。两轴机构只覆盖两个旋转自由度，基座引入的第三个姿态自由度（横滚）没有对应的轴去抵消。装得再正也没用，因为平台在动。

运动学与耦合

设相机光轴单位向量在载体坐标系下为：

1

x_c = ( cos t·cos p ,  cos t·sin p ,  −sin t )        // p = pan, t = tilt

载体相对水平面的小失准向量 δ = (φ_b, θ_b, δ_ψ)（前向滚转 / 侧向俯仰 / 航向）。图像 Roll 即 δ 在光轴上的投影（一阶近似）：

1

ρ ≈ δ · x_c = cos t · (φ_b·cos p + θ_b·sin p) − δ_ψ·sin t

这条公式是理解 PTZR 一切工程决策的核心，三个直接结论：

  1. Pan 会"连累"Roll。载体固定倾斜下，只做一次 Roll 归零，Pan 扫过 360° 时 ρ 按正弦重现，幅值 = √(φ_b²+θ_b²) = 载体倾角。船体横摇 5°、Pan 转 90°，图像 Roll 就从 0 摆到 5°。→ Roll 必须随 Pan/Tilt 实时联动，静态标定一次解决不了。
  2. Tilt 抑制横滚。cos t 因子说明大仰角时载体倾斜对 Roll 的贡献变小，但 δ_ψ·sin t 项接管——抬头时航向误差直接变成画面旋转。
  3. 天顶奇点。t → ±90° 时光轴与铅垂轴平行，Pan 与 Roll 产生完全相同的图像效果，雅可比降秩（万向锁）。过顶保持地平线需要 Pan 瞬时 180° 翻转（速率 → ∞）。工程做法：设 70° 告警 / 85° 冻结，或加第四根冗余轴主动维持轴间夹角；姿态解算全程用四元数，只在末端解算电机角。

修正常见误解：纯 Roll 像素代价与焦距无关。30x 下 0.3° 难忍的真实原因有三个：① 4K 角点 11.5 px 往复抖动在 1/50s 快门下即可见拖影；② 长焦时 pan/tilt 残差已经吃掉全部误差预算，Roll 没有余量；③ 真正被焦距放大的是下一节的 Roll 轴偏心视差。

横滚轴机械：轴必须压在光轴上

旋转型视差（Roll-axis parallax）：若 Roll 旋转中心偏离光轴 d，转动 φ 时入瞳横移 Δ = d·sinφ，对距离 L 的被摄物形成视差角 α = d·sinφ / L，像素位移：

1

Δpx = f_px · d·sinφ / L ，其中 f_px = 图像宽 / (2·tan(HFOV/2))

取 d = 0.5 mm、φ = 15°（Δ = 0.13 mm）、1920 宽：

变焦HFOVIFOVL=5 mL=1 m

即 d < 0.5 mm 在广角完全无感，长焦近景就是数像素级整体平移 + 近远景不同步的梯形 / 透视畸变。若要求 30x、L=2 m 下 <1 px，需 d·sinφ < 42 µm → d < 0.16 mm。这是装配硬约束：Roll 轴承同心度、镜头组光轴与机械轴对准，通常靠出厂光学打靶 + 偏心垫片补偿。

布置选择两条路：

  • 转整个光机块（镜头 + sensor）：光轴与机械轴天然共轴，无镜-感失配，代价是转动惯量大（Tail 2 整机 1.066 kg）。
  • 只转 sensor：惯量最小、带宽最高，但 sensor 中心与光轴偏心 d 直接暴露，且需柔性排线（寿命 / 回弹力矩）。

Roll 电机扭矩最小（典型 0.020.1 N·m 直驱 BLDC）；用减速箱会引入 0.020.1° 背隙，直驱无背隙但需大电流保持力矩。带宽阶梯典型：Pitch 30~60 Hz > Roll 15~30 Hz > Yaw 10~20 Hz（Yaw 惯量最大）。Roll 常是稳定链路的实际短板。

自动水平控制（Horizon Lock）

方案 A：IMU / 陀螺。加速度计给长期水平基准（互补滤波截止 0.050.5 Hz），陀螺给短期高带宽（>0.5 Hz），环路 2001000 Hz。不依赖场景、延迟 <5 ms。缺点：消费级 MEMS 零偏不稳定 10100 °/h，加计零偏温漂使 Roll 零位漂 0.050.3°/10 ℃；载体横向加速度污染重力基准（车辆转弯"假倾斜"），需车速 / GNSS 或转弯率补偿。

方案 B：视觉地平线。中值滤波 → Canny 边缘 → Hough 变换取直线 → 约束筛选（长度 / 贯穿性 / 天顶消失点几何）→ RANSAC / 最小二乘拟合 → 反解 Roll。精度 0.10.5°，延迟 24 帧（60130 ms），只能做慢外环（<12 Hz）。纯天空 / 雾天 / 密林 / 长焦特写等无地平线场景直接失效，需置信度门限 + 优雅退化。

方案 C（主流）：融合。IMU 跑内环粗稳（高带宽），视觉以 0.1~1 Hz 在线估计并抵消 IMU 零偏（EKF 中把 Roll bias 作为状态量）。等效"陀螺管动态、视觉管静态"，既消漂移又不受帧率限制。

三轴稳定是三路串级环：电流环 1020 kHz → 角速率环（陀螺反馈）5001000 Hz → 角度 / 姿态环 100~200 Hz。两个关键点：前馈把载体 IMU 角速率直接送到各轴速度指令，不等误差累积——这是三轴云台优于两轴的核心；解耦把 cos t·(φ_b·cos p + θ_b·sin p) 前馈给 Roll 轴，避免 Roll 环去"追"自己造成的可预测误差。相对 PTZ，控制器算力与内存约 +50%。

4-DOF 标定在 PTZ 三维查找表之上追加：Roll 机械零位（水平仪 / 自准直仪基准，<0.05°）、Roll–光轴同心度（远近双靶标法反解 d，垫片补偿至 <0.2 mm）、Roll 与 Pan/Tilt 正交度。长期漂移：结构蠕变 + 温漂使 Roll 零位年漂 0.10.3°，建议整机 312 个月复标，或在线自标定——静止且有可靠地平线时用视觉估计值刷新零位。

行业通用 EIS 裁切量 5~20%。电子法的三条硬边界：

  1. FOV 不可逆损失，广角端损失最刺眼（上表 4~6°）；
  2. 长焦端不可用：裁切百分比与焦距无关，但长焦本已进入数字变焦区、无冗余像素，再裁 10% 直接掉 MTF，旋转重采样再降 10~20% 锐度；
  3. 旋转中心必须 = 光心。若已做数字 pan/tilt 裁切，旋转中心偏离光心 Δc，旋转 φ 会额外引入平移 Δc·2sin(φ/2) 与残余梯形——正是"数字防抖画面边缘游走"的成因。

选型边界：长焦（>10x）、需保全 FOV、船载 / 车载 / 摇臂等大幅持续倾斜 → 必须机械 Roll；广角、θ < 5°、成本 / 体积敏感、纯手持微抖 → EIS Roll 足够；高端方案是机械粗稳（±15°，15~30 Hz）+ EIS 精修（±1°，逐行 rolling shutter 校正），机械管幅值、电子管高频与果冻效应，裁切压到 3% 以内。

船载是 PTZR 的 “Killer App”：横摇是绕纵轴旋转，两轴云台在运动学上根本无法合成这个旋转分量。JH602 舰载指标：横纵摇 ≤10° 且周期 >6 s 时 LOS 稳定 ≤1 mrad；>10°~22.5° 仅"可正常工作"。

决策边界：基座静态倾角 >2° 或动态横摇幅值 >1.5° → 必须上 PTZR；长焦 >20x 时横摇阈值降到 >0.3°（长焦把同样的横滚误差放大到不可见——不，是不可容忍）。纯固定杆 / 室内桌面 → PTZ 足够，Roll 用一次性机械调平（SD530H 模式）性价比最高。

PTZR 特有的稳定性问题

  • 共振模态 2→3：内层 Roll 框把 Pitch 框变成"带柔性支撑的悬臂"，模态耦合。Notch 从 2 组变 3 组且互相牵连，需在线模态辨识而非固定 Notch。
  • Roll 轴带宽最窄（15~30 Hz），成短板：DJI Z15-A7 的 Roll 轴最大控速仅 ±30°/s，Pan/Tilt 是 ±130°/s（约 1/4）。Roll 电机在最内层、力矩臂最短、要驱动全部外层惯量，载体高频横摇（>20 Hz，车载路面激励典型）漏稳。缓解以机械为主（Gremsy T7 三轴统一到 180°/s）。
  • 延迟叠加与过冲：控制回路 2→3 后，姿态解算（四元数 → 三轴解耦）+ 死区时间叠加，典型 +13 ms，三轴联动指令易在 Roll 上过冲。工程做法：三轴共用同一 IMU 时间戳、统一 12 kHz 电流环、Roll 单独加低增益前馈。
  • 无地平线场景自动水平失效：纯海面 / 雪原 / 天空 / 夜景无水平线特征 → 视觉法退化，必须 IMU 兜底；SOMAG 额外融合船 NMEA 数据抑制长期漂移。
  • 横滚偏心视差（未解决）：Roll 轴需与光学入瞳 / 节点重合，装配偏心 δ 在物距 D、焦距 f 下像移 ≈ f·δ/D。长焦近景（f=550 mm、D=2 m、δ=0.2 mm）像移达 55 µm ≈ 十余像素，转 Roll 即"抖"。约束通常订到 <0.2 mm，量产良率是痛点。
  • 天顶奇点（tilt→±90°）：Pan 与 Roll 轴共线，自由度塌陷。规避：① 机械限位避开（H20T 可控 pitch 仅 −120°~+30°，刻意不给 ±90° 停留）；② 接近奇点时冻结 Roll 只用 Pan；③ 四元数插值 + 奇点邻域速度限幅。

标准与生态：FreeD 天生带 Roll

FreeD（BBC R&D 起源）的 D1 包 29 字节，天然 6DOF + 2 镜头轴 = Pan / Tilt / Roll（各 24-bit，±180°，分辨率 1/32768°）+ X/Y/Z + Zoom/Focus + 校验位，UDP 默认端口 40000。虚拟生产（UE Live Link FreeD、disguise、Mo-Sys、stYpe、Ncam）开箱支持 Roll，PTZR 在 VP 中零协议改造成本。

缺口也在这里：ONVIF 无 Roll 字段（PTZ Vector 仅 PanTilt+Zoom）、VISCA 无 Roll 命令。厂商只能走私有扩展——Bolin 把 Roll 叫 “Image Rolling Adjustment ±15°” 挂在菜单外；OBSBOT 靠 WebUI / 私有 SDK。NDI 传视频不传位姿，Roll 元数据须旁路 FreeD。

PTZR 在 VP 的价值：AR 图层需要正确的 Roll 才不"漂"。Tail 2 用 ±0.003° 角抖 + FreeD + UE 插件，把 VP 入门成本从 stYpe / Mo-Sys 的十万美元级压到千美元级。

选型 Checklist

  • 平台静态倾角 >2° 或动态横摇 >1.5°（长焦 >20x → >0.3°）？是 → 必须机械 Roll。
  • 需要保全 FOV（长焦 >10x）？是 → 机械 Roll，放弃 EIS 旋转裁切。
  • 需要无损竖屏（短视频）？是 → 物理 ±90° 转轴（OBSBOT Tail 2 类）。
  • 需要 VP / AR 图层？是 → 必须支持 FreeD（含 Roll）。
  • Roll 轴偏心 d 装配公差 <0.2 mm（长焦近景 <0.16 mm）？是 → 出厂打靶 + 垫片。
  • 会出现无地平线场景（海面 / 天空）？是 → 必须 IMU 兜底 + 外部姿态源融合。
  • 需过顶拍摄（tilt→±90°）？是 → 机械限位避开奇点，或四元数解算 + 速度限幅。

标准层面的终局与前文呼应：多厂商标准分裂在 PTZ 时代是结构性问题，PTZR 更尖锐——ONVIF / VISCA 根本没有 Roll 字段，FreeD 虽带 Roll 但只用于 VP 小圈子。跨安防 / 广电 / 无人机三界的统一 Roll 元数据标准，目前还不存在。
