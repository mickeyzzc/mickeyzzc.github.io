国产大模型资源与成本对比：GLM、Kimi、MiniMax、DeepSeek、Qwen、豆包、小米 MiMo

March 23, 2026 September 23, 2026 AI工具 GLM, Kimi, MiniMax, DeepSeek, Qwen, 豆包, 小米, 大模型 3501 字 8 分钟阅读

概览

本文 2026-03 首发时对比 GLM-5 / Kimi K2.5 / MiniMax M2.7 三家；2026-09 扩到七家，按角色分四档：旗舰三强（GLM-5.3 / Kimi K3 / MiniMax M3）、价格锚点（DeepSeek、Qwen）、调用量最大的豆包、新晋黑马（小米 MiMo）。数据时点 2026-09-23，价格为公开刊例价——各家 2026 年内多次调价，下单前以官方定价页为准。

模型厂商架构权重一句话定位

Kimi K3月之暗面MoE，2.8T 总参，KDA 混合线性注意力开源能力上限，定价也最贵

价格大势：2026 上半年先降价后涨价，方向整体向上。Kimi 旗舰输入价涨到原来的 5 倍，GLM 相对 GLM-4 时代提价 67%-100%，DeepSeek 8 月 13 日部分模型涨幅超三倍；行业 2026Q2 平均 API 价到了输入 4.9 元 / 输出 21.9 元每百万 tokens。

GLM-5.3（智谱AI）

版本与硬件需求

主线是 GLM-5（2026-02 开源，MIT 协议，744B 总参 / 40B 激活，200K 上下文）→ GLM-5.1 → GLM-5.2（上下文扩到 1M，开源权重）→ GLM-5.3。5.3 与 5.2 共用基座，提升全部来自后训练，复杂编程与 Agent 任务是主打。

  • GLM-5.3：旗舰，1M 上下文，最大输出 128K。
  • GLM-5.3-Flash：轻量档，1M 上下文，首个采用稀疏注意力 + 线性注意力混合架构的开源前沿模型，思考模式常开，已全量接入 GLM Coding Plan。

本地部署：FP8 全量约需 860GB 显存，典型方案 8 张 B200（192GB）；1M 上下文时 KV Cache 另加约 103GB。社区有 8-24GB 显存的低比特量化方案，能跑，生产环境别指望。

Kimi K3（月之暗面）

版本与硬件需求

Kimi K3 于 2026-07-17 发布：2.8T 总参，全球最大的开源模型之一；1M 上下文；自研 KDA（Kimi Delta Attention）混合线性注意力 + 注意力残差；原生多模态。权重开源，但这个体量只有服务器集群能伺候。

中档在售的是 K2.6 和 K2.7 Code（输入 $0.95 / 输出 $4.00 每百万）。首发时对比的 K2.5（$0.60/$3.00）还在卖，但已不是主力档。

成本

项目价格（每百万 tokens）
输入（缓存未命中）~$3（约 ¥21）
输入（缓存命中）~$0.3
输出~$14（约 ¥100）

这是目前国产主流模型里的最高定价，对标 GPT-5.6 Terra；输入价是自家 K2.7 Code 的 3 倍，输出 3.7 倍。买的是能力上限，不是性价比。

MiniMax M3

版本与硬件需求

MiniMax M3 于 2026-06-01 发布并开源：428B 总参 / 23B 激活，MSA 稀疏注意力（官方口径 prefill 提速 9.7 倍、decode 15.6 倍），原生多模态，1M 上下文（1,048,576 tokens），thinking 与 non-thinking 双模式。

上一代 M2.7（2026-03-18 发布，4 月开源，229B MoE）仍在售，分 M2.7 与 M2.7-highspeed 两档，结果一致、后者更快。

本地部署：428B/激活 23B 在旗舰里门槛最低，量化后多卡工作站（8×A100/H100 级）可跑，是自部署的现实选项。

DeepSeek V4（深度求索）

版本与硬件需求

DeepSeek V4 分 Pro / Flash 双线，权重开源（SiliconFlow 等第三方平台直接托管）。计费有个别家少有的设计：高峰/空闲分时定价，夜间跑批量任务能省一半输出费用。

2026 年价格走了个大来回：4 月两天两次降价（缓存命中输入低至 0.02 元），5 月 V4-Pro 永久降价 75%，6 月底调价，8 月 13 日大幅调价——部分模型涨幅超三倍，同步推出 V4 Pro 正式版。现在用 DeepSeek 前先看一眼最新公告，它的刊例一年能变四回。

Qwen（阿里云百炼）

版本与硬件需求

Qwen 是国产开源系列里生态最全的一家，自部署社区的事实标准。API 在售多档：旗舰 Qwen3.8-Max（2026-08 发布，主打编程与协作）、性价比档 Qwen3.5-Plus、长文本档 Qwen-Long、多模态 Omni 系列（文本 1.8 元、音频 15.8 元、图片/视频约 3.3 元每百万）。新用户每模型有 100 万 token 免费额度。

豆包 2.1（字节跳动·火山引擎）

版本与硬件需求

豆包是调用量最大的国产模型家族——字节口径日均 token 用量突破 180 万亿。当前主力：豆包 2.1（2026-06 发布，Seed 2.x 系列，Agent 模式可自主跑长任务）、Seed 2.0 Pro、Doubao-Seed-Evolving（编程与 Agent 模型，持续升级不发版）。旗舰线未开源。

小米 MiMo

版本与硬件需求

小米是 2026 年冲得最猛的新玩家。时间线：2025-12 开源 MiMo-V2-Flash → 2026-03 V2 系列 → 2026-04 V2.5-Pro 登顶全球开源第一 → 2026-09-22 发布并开源 MiMo-V2.6 Pro 与 Flash。V2.6-Pro 是万亿参数旗舰、全模态，IntelligenceIndex 评测 46 分——超过 Kimi K3 的 44 分；小米同时公开了六天 LiveRL 训练全过程（Pro 训练成本约 262 万美元、Flash 约 85 万美元）。API 兼容 OpenAI 格式，分 MiMo-V2-Flash（轻量）和 V2-Pro（复杂推理）两档。

成本

V2.6 发布仅一天，新刊例尚未被公开渠道收录，以 mimo.mi.com 为准。最后一代可查的 V2.5 刊例：标准版输入 1 元 / 输出 2 元（缓存命中 0.02 元），Pro 版输入 3 元 / 输出 6 元（缓存命中 0.025 元）——全面对标 DeepSeek，官方口径约为国际竞品的 1/5。

选型建议

高频廉价与兜底：DeepSeek V4-Flash、Qwen3.5-Plus、MiMo 标准档，月百万 token 都在 1-3 元量级；DeepSeek 和 MiMo 的缓存命中价低至 0.02-0.05 元，固定 System Prompt 长的任务优先吃缓存。

编程与 Agent 主力：GLM-5.3（旗舰档 8/28 性价比最好）、Qwen3.8-Max、豆包 Seed-Evolving（配火山工具链和长时 Agent 任务）。

能力上限优先：Kimi K3（2.8T + 1M 上下文 + 原生多模态，输出最贵）和 MiMo-V2.6-Pro（IntelligenceIndex 46 分新晋第一），两个都买得起就都留着做对照。

自部署：Qwen 开源系列生态最全、文档最多，是默认起点；DeepSeek、MiniMax M3、MiMo 权重也都开放，M3 的 428B/23B 是多卡工作站里最现实的旗舰。GLM 和 K3 是服务器级起步。

总结

七家的格局：旗舰档 GLM、Kimi、MiMo 互搏，DeepSeek 和 Qwen 是价格锚，豆包靠量，小米是涨价潮里唯一一个用超低价冲进第一梯队的新玩家。2026 年的教训是刊例靠不住——DeepSeek 一年变四回价，GLM、Kimi 也在涨，采购前把官方定价页和自家用量结构（输入输出比、缓存命中率）都过一遍。数据时点 2026-09-23。
