国产大模型资源与成本对比：GLM-5.3 / Kimi K3 / MiniMax M3

March 23, 2026 September 23, 2026 AI工具 GLM, Kimi, MiniMax, 大模型 1880 字 4 分钟阅读
🔊

概览

本文 2026-03 首发时对比的是 GLM-5 / Kimi K2.5 / MiniMax M2.7，2026-09 已更新至三家当前旗舰。数据时点 2026-09-23，价格为公开刊例价——各家 2026 年内多次调价，下单前以官方定价页为准。

模型厂商架构上下文权重API
GLM-5.3智谱AIMoE，约 753B 总参 / 40B 激活1M基座开源（GLM-5 为 MIT）✅

半年的大势是换代加涨价：Kimi 旗舰输入价涨到原来的 5 倍，GLM 相对 GLM-4 时代提价 67%-100%，行业 2026Q2 平均 API 价到了输入 4.9 元 / 输出 21.9 元每百万 tokens。

GLM-5.3（智谱AI）

版本与硬件需求

主线是 GLM-5（2026-02 开源，MIT 协议，744B 总参 / 40B 激活，200K 上下文）→ GLM-5.1 → GLM-5.2（上下文扩到 1M，开源权重）→ GLM-5.3。5.3 与 5.2 共用基座，提升全部来自后训练，复杂编程与 Agent 任务是主打。

  • GLM-5.3：旗舰，1M 上下文，最大输出 128K。
  • GLM-5.3-Flash：轻量档，1M 上下文，首个采用稀疏注意力 + 线性注意力混合架构的开源前沿模型，思考模式常开，已全量接入 GLM Coding Plan。

本地部署：FP8 全量约需 860GB 显存，典型方案 8 张 B200（192GB）；1M 上下文时 KV Cache 另加约 103GB。社区有 8-24GB 显存的低比特量化方案，能跑，生产环境别指望。

Kimi K3（月之暗面）

版本与硬件需求

Kimi K3 于 2026-07-17 发布：2.8T 总参，全球最大的开源模型之一；1M 上下文；自研 KDA（Kimi Delta Attention）混合线性注意力 + 注意力残差；原生多模态。权重开源，但这个体量只有服务器集群能伺候。

中档在售的是 K2.6 和 K2.7 Code（输入 $0.95 / 输出 $4.00 每百万）。首发时对比的 K2.5（$0.60/$3.00）还在卖，但已不是主力档。

MiniMax M3

版本与硬件需求

MiniMax M3 于 2026-06-01 发布并开源：428B 总参 / 23B 激活，MSA 稀疏注意力（官方口径 prefill 提速 9.7 倍、decode 15.6 倍），原生多模态，1M 上下文（1,048,576 tokens），thinking 与 non-thinking 双模式。

上一代 M2.7（2026-03-18 发布，4 月开源，229B MoE）仍在售，分 M2.7 与 M2.7-highspeed 两档，结果一致、后者更快。

本地部署：428B/激活 23B 在三家旗舰里门槛最低，量化后多卡工作站（8×A100/H100 级）可跑，是自部署的现实选项。

对比半年前：当时 K2.5 官方口径月均 4700 元、M2.7-基础版 16 元的算法里输入输出配比没写清，数字不可比；现在这版统一按 8:2 配比计算，可横向对比。

选型建议

省钱和高频调用：GLM-5.3-Flash 或 MiniMax M3，走订阅套餐（GLM Coding Plan / MiniMax Token Plan）通常比按量付费划算。

编程与 Agent 主力：GLM-5.3，旗舰档 8/28 的定价是三家旗舰里性价比最好的。

能力上限优先：Kimi K3，2.8T 参数 + 1M 上下文 + 原生多模态，价格也是国产最贵。

本地部署：三家旗舰都是服务器级——GLM 要 8×B200 起，K3 是集群级，M3 的 428B/23B 是多卡工作站里最现实的。消费级显卡只剩社区低比特量化方案，玩玩可以，生产别用。

总结

2026 上半年的主线是换代加涨价：旗舰越卖越贵（Kimi K3 输出 ¥100/M），便宜档从"旗舰低价"迁移到 Flash/轻量款和订阅套餐。当下按需选：高频廉价用 Flash 档和 Token Plan，编程主力用 GLM-5.3，能力上限买 K3。数据时点 2026-09-23，各家调价频繁，下单前核对官方定价页。
