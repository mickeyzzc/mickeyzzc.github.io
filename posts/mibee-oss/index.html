onvif-c 教程：给 ESP32 固件装上 ONVIF 设备端

October 3, 2026

onvif-c 是五个协议库里最「物理」的一个：ESP-IDF 上的 plain C ONVIF 设备端组件，约 10KB 代码足迹、零第三方依赖。ESP32 相机固件想被 NVR 发现、读设备信息、拿到流地址、上报移动侦测事件，加这一个组件就够了。它没有 XML 解析器——动作识别用 strstr()，响应用 snprintf() 拼——内存模型简单到从传感器回调上下文里调用也安全。四个 MiBee 相机固件仓随固件同步携带它，库的改动先在真机上过一遍再发布。

onvif-device-rs 教程：用 Rust 实现一台 ONVIF 相机

October 2, 2026

onvif-device-rs 管的是 ONVIF 的另一半：onvif-go 是「连相机」，这个库是「当相机」——让 NVR 把你的设备当成一台 ONVIF 摄像机来发现、读信息、取流、控云台、收事件。适用场景：把 Linux 板子或工控机做成 ONVIF 相机、给 NVR 开发造测试桩、把 PC 摄像头挂进 NVR。它是 Rust 侧此前没有的 ONVIF 设备端实现，从 MiBee 的树莓派相机固件原样抽出，响应字节级稳定，与 MiBeeNvr 逐字节互操作。
